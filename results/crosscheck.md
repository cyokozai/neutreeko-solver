# 後退解析の表と独立 αβ 検証器の突き合わせ

`scripts/crosscheck.jl` の出力。後退解析（`src/`、module `Neutreeko`）が作った全局面の表から局面を選び、コードを共有しない前向きの αβ 探索（`verify/Oracle.jl`、module `NeutreekoOracle`）で同じ局面を読み直して、値（勝ち・負け・引分け）と決着までの手数（ply）が一致するかを確かめた。

判定規則（`verify/compare.jl` と同じ）: 表が勝ち・負けで距離 d ≤ maxdepth なら oracle が同じ値・同じ距離を返すこと。表が引分け、または d > maxdepth なら oracle が maxdepth 手以内に決着しない（`:unknown`）こと。oracle は反復深化なので、距離 d で決着を返したことは d − 1 手以内では決着しないことも含む。

**要約**: (a)〜(c) の問い合わせ計 6,942,827 回、補足の TSV 経由 20,000 回のいずれも**不一致 0 件**。

| (b) 初期局面の 14 手（maxdepth = 距離 と 距離 − 1、引分けは 20） | 27 | 0 |

## 補足

### コミットについて

「本体のコミット」は `src/` を含む #2（`feat/core-retrograde`）の先端。突き合わせのスクリプト（`scripts/crosscheck.jl`, `scripts/export_tsv.jl`）はその上の `feat/crosscheck` にあり、`src/` には手を加えていない。検証器は #4（`feat/verify-alphabeta`）の `verify/Oracle.jl` をそのコミットから取り出して使った（取り込んではいない）。

### 所要時間について

上の秒数は、同じホストで別の Julia コンテナ（並行して作業している他担当のもの）が CPU を 3〜4 コア分使っている間に測った値で、占有して測れば短くなる。桁の目安として読むこと。(b) の最も深い問い合わせ（初手 `b1-b4` / `d1-d4` の後の白番局面、maxdepth 21）は 1 回 11〜13 秒だった。

### TSV を経由した突き合わせ（`export_tsv.jl` → `verify/compare.jl`）

上の検査は検証器をスクリプトから直接呼んでいる。表記の取り決めが TSV でも通ることを確かめるため、書き出しと検証器の CLI をそのままつないだ。

| 入力 | 件数 | maxdepth | 結果 |
|---|---:|---:|---|
| `export_tsv.jl --sample 20000 --side random`（勝ち 14,177 / 負け 5,249 / 引分け 574） | 20,000 | 9 | `checked=20000 mismatches=0 skipped_invalid=0`、25.4 秒（1 スレッド） |
| 検証器の `fixtures/table_ok.tsv` の 9 局面を `export_tsv.jl --positions` で表から引き直したもの | 9 | — | 検証器側が手で確かめた値・距離と全行一致（引分けの距離の書き方が 0 と -1 で違うだけ） |

`skipped_invalid=0` は、書き出しが無効局面（手番側が並び済み・両者並び）を含まないことの確認にもなっている。

### 局面表記の取り決め

本体の `format_position` と検証器の `format_pos` は同じ規約（`"<手番>:<25文字>"`、sq = 0..24 = a1..e5）で、(a) の全抽出局面で相互に同じ文字列に戻った。違いは引分けの距離の書き方だけで、本体の `lookup` は -1、検証器の fixture は 0 を使う。`compare.jl` は引分けの距離を見ないので、結果には影響しない。

### 再現手順

```sh
# 表を作る（data/ に保存。約 1 秒）
docker run --rm -v "$PWD":/work -w /work julia:1.11 julia --project=. scripts/solve.jl
# 突き合わせ（verify/ があればそれを使う。無ければ --oracle で Oracle.jl のパスを渡す）
docker run --rm -v "$PWD":/work -w /work julia:1.11 julia -t 8 --project=. scripts/crosscheck.jl \
  --shallow-all --core-sha <本体の SHA> --oracle-sha <検証器の SHA> --host "<ホストの説明>" \
  --out results/crosscheck.md
# TSV を経由した突き合わせ
docker run --rm -v "$PWD":/work -w /work julia:1.11 bash -c \
  'julia --project=. scripts/export_tsv.jl --sample 20000 --side random --out /tmp/s.tsv &&
   julia verify/compare.jl /tmp/s.tsv --maxdepth 9'
```
